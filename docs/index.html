YouTube OAuth Manager

A desktop utility for signing in to Google accounts through Google's official OAuth consent flow, managing YouTube account authorizations, and exporting user-authorized OAuth credentials for use in a local YouTube chat management application.

Access to YouTube information, chat messages, or subscription actions is requested only with the account holder's authorization. Token data can be saved locally and exported by the user.

This is an independent application and is not affiliated with Google or YouTube.
